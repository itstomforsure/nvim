# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

- Default configuration, with the following extras:
  - Took some plugins from the example.lua file and put them into separate files:
    - Telescope
    - Treesitter
    - Trouble
    - Tokyonight --theme
    - Snippets
    - Mason
    - lazyvim.plugins.extras.lang.typescript,
    - lazyvim.plugins.extras.ui.mini-starter,
    - lazyvim.plugins.extras.lang.json
    - lsp-config with update_in_insert and inlay_hints = true
